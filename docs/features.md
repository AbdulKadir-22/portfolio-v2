# Feature Overview & Directory Guide

This document lists the main features included in the portfolio application and maps out their respective implementation directories.

## Features

### 1. 🪐 Orbiting Skills System (`/src/features/skills`)
Interactive planetary system mapping technical specialties (Frontend, Backend, Databases, Tools & DevOps) as celestial bodies in orbit.

### 2. 📁 Projects Showcase (`/src/features/projects`)
Filterable catalog showcasing web applications, full-stack tools, and open-source packages with custom layout grid toggles and detail modals.

### 3. ⏳ Journey Timeline (`/src/features/experience`)
Interactive timeline highlighting academic research, industry roles, and open-source milestones.

### 4. ✍️ Literature Corner (`/src/features/literature`)
Creative showcase featuring original poetry, ongoing novel progress metrics, and curated personal quotes.

### 5. ✍️ Blog Archive (`/src/features/blogs`)
Technical and personal article archives formatted for clean readability with route-based detail pages.

### 6. 🎨 Personal Hobbies & Interests (`/src/features/hobbies`)
Visual grid mapping favorite books, films, and artistic pursuits.

### 7. 📬 Contact Hub (`/src/features/contact`)
Interactive communication hub with dynamic connection links and message forms.
